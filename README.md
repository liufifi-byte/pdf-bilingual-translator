# PDF 双语翻译

上传一份 PDF，左边看原文、右边看译文，译文**原位渲染在原版面的位置上**——标题还是标题的位置，表格还是表格的位置。滑到哪页翻哪页，翻完可一键下载整本译文 PDF。

## 功能

- **原位对照阅读**：左侧原文画布 + 右侧原位译文浮层，段落按阅读顺序逐段"点亮"，翻译进度一目了然。双栏报告自动按"先左栏后右栏"的阅读顺序翻译。
- **按页懒翻译**：不需要先翻完整本。滚动到哪页才翻译哪页，翻译中未完成的段落置灰占位。
- **多目标语言**：源语言自动检测；目标语言支持中文、英文、韩文、日文、西班牙文、俄文，翻译中途可切换（旧缓存自动作废重译）。
- **术语库**：维护"原文术语 → 标准译法"，作为最高优先级注入每次翻译；改完术语可对已译页面一键重译。
- **AI 概括**：翻译前先看文档要点——一句话总览 + 5-8 条关键要点（数字、名称均来自原文）。
- **整本译文 PDF 下载**：全量翻译后生成保留原版面的双语 PDF（数字/页眉/图表区域原样保留，中文字体自动适配宋体）。
- **格式保护**：数字、单位、化学式、代号、URL、公司机构名不翻译；页眉与图表内文字原样保留。

## 技术架构

```
frontend/  React + antd + pdf.js   左右对照阅读器、流式译文浮层
backend/   FastAPI + PyMuPDF       PDF 解析(双栏/表格/图表识别) → LLM 批量翻译 → 原位渲染
```

- **批量翻译协议**：单页多个文本块用 `[编号]` 协议合并成 1-3 次 LLM 调用（逐块调用一页要 30-80 次），漏译/串号自动回退单条重译。
- **流式体验**：后端按批发布部分结果，前端 1s 轮询，译文逐批上页。
- **LLM 可插拔**：默认 Stub 占位（无需 key 即可跑通界面）；配置 `.env` 即接智谱云或任何 OpenAI 兼容 endpoint。

## 快速开始

### 1. 后端

```bash
cd backend
python -m venv .venv && source .venv/bin/activate   # 或用你惯用的环境
pip install -r requirements.txt

# (可选) 配置模型: 不配置则用 Stub 占位实现
cp .env.example .env   # 填入你的 GLM_API_KEY

uvicorn app.main:app --port 8000
```

### 2. 前端

```bash
cd frontend
npm install
npm run dev
# 打开 http://localhost:5173
```

### 3. 使用

上传 PDF → 等待解析完成 → 选目标语言 → 点「开始翻译」→ 滚动阅读，或点「下载报告」生成整本译文 PDF。

## 模型配置说明

| 变量 | 说明 |
|------|------|
| `LLM_BACKEND` | `stub`（默认，占位实现）/ `glm`（真实翻译） |
| `GLM_API_KEY` | 智谱云 API key（格式 `id.secret`，会自动生成 JWT）或兼容端点 token |
| `GLM_MODEL` | 模型名，默认 `glm-4.6` |
| `GLM_BASE_URL` | OpenAI 兼容私有化端点；留空走智谱云 |

> 未配置 key 时自动回退 Stub，服务不会启动失败。

## 运行测试

```bash
cd backend
pytest
```

## 说明

- 文档列表与译文缓存在内存中，重启后清空；术语库持久化在 `backend/data/glossary.json`。
- 扫描件（纯图片 PDF）需要 OCR，当前版本不处理。
